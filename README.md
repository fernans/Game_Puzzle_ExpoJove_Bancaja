# Game_Puzzle_ExpoJove_Bancaja

Flash (2006/2007) jigsaw-puzzle game built for the Bancaja ExpoJove youth fair,
by Mediterrania Multimedia — hence its original HTML title
"*Juegos Bancaja ExpoJove 2007*". The player assembles a picture; the folder
`material/` contains the four source photos with their 3×3 sliced pieces
(`material/images/`), an HTML player per photo, and a set of third-party Flash
games of the DGT road-safety campaign (`material/juegos_DGT/`) used as
reference/inspiration. `licencia.txt` holds an era #id placeholder (not real
data); `progreso/` keeps intermediate FLA iterations.

> **This project is shared ONLY for educational purposes. Its use, direct or derived, for professional or economic purposes is not permitted.**

For security/integrity reasons, no part of the project needed to be edited or removed: everything is kept as it was left in 2006/2007, including the third-party DGT game files and the `licencia.txt` data as-is.

## Requirements / How to run

- Open `Puzzle.swf` (or `Puzzle.html`, which loads the SWF at 800×600) in a
  Flash Player 8 era runtime, or open `Puzzle.fla` in Flash 8 / CS to edit the
  game and swap the pictures to slice.

Bancaja, por Mediterrania Multimedia — de ahí su título HTML original
